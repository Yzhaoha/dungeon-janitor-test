# 美术交接（给本地画图会话）

> 这份文档是给用户在自己 Mac 上新开的 Claude Code 本地会话看的。那个会话**只负责画图**：在用户已登录的 ChatGPT 网页里生成图片、下载、整理、放进仓库。**不要改游戏代码**，接进游戏由云端会话做。
> 全程中文回复，用户不看代码只看效果，说话直白少术语。

## 背景
- 游戏：Potion Knight: Save the Princess（药水骑士：拯救公主），仓库 Yzhaoha/dungeon-janitor-test，测试链接 https://yzhaoha.github.io/dungeon-janitor-test/
- 玩法：下面倒药水分颜色，上面骑士和怪物回合战斗。现在人物、怪物、场景都是代码画的，用户嫌不够精致，决定用 ChatGPT 画正式美术替换。
- 想先看现在的样子：打开测试链接玩一下，或者看 `covers/` 里的封面图。

## 用户规矩（必须遵守）
- 不替用户注册、不输入任何密码；需要登录就停下来让用户自己登。
- 用户邮箱不写进仓库。
- 有花钱的选项（比如额外购买次数）先问用户。

## 怎么画
1. 在 ChatGPT 网页里**新开一个对话，所有图都在这同一个对话里画**，这样风格才统一。
2. 先发下面「统一画风」那段，再画第 1 张（骑士）。**骑士画好先给用户看，用户点头了再画别的。**
3. 之后每张都在提示词后面加一句：`Same art style, line weight, lighting and level of detail as the knight above.`
4. 每张要求：**透明背景 PNG**、正方形 1024×1024（场景图除外）、全身、不要地面阴影、不要文字、不要边框、角色居中占高度约 80%、脚底贴近画面下沿（留一点空）。
5. 如果 ChatGPT 给的不是透明背景，再追一句 `Make the background fully transparent and give me the PNG.`，还不行就让背景是纯白，记在清单里，云端会话会处理抠图。
6. 下载原图，不要截图（截图会糊）。

### 统一画风（第一句先发这段）
```
2D game character art for a dark-fantasy mobile puzzle game. Hand-painted look, bold dark outlines, rich shading and rim light, slightly stylized but NOT chibi and NOT cute: realistic proportions, menacing and cool. Full body, side view, plain transparent background (PNG), no shadow on the ground, no text, no frame. 1024x1024, character centred and filling about 80% of the height, feet near the bottom edge.
```

## 交付
1. 所有 PNG 放进仓库 `art/` 文件夹，文件名照上表。
2. 另写一个 `art/清单.md`：每张一行，写「文件名 / 是否透明背景 / 用户是否满意 / 备注」。
3. 提交到分支 `art-assets`（**不要推到 main**），推上去后告诉用户“图放好了，分支 art-assets”。
4. 用户回到云端会话说一声，云端会话会负责：抠图（如需要）、压缩成小文件、换进游戏、加动作（呼吸、冲锋、挨打闪白、倒地、马跑）、按装备等级换骑士图、重新做封面和预览视频。

## 接进游戏时的取舍（已和用户说过）
- ChatGPT 每张只有一个姿势，动作还是靠整张图移动、旋转、挤压、闪白。
- 「换装备换造型」改成按胸甲等级换整套骑士图（4 张），其他部位装备只加数值不改外观。
- 瓶子、药水、塞子、护盾、刀光火焰、按钮、血条、小地图、翻牌等继续用代码画，不需要 ChatGPT 画。
