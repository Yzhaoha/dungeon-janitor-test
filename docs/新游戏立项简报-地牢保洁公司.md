# 新游戏立项简报：地牢保洁公司（Dungeon Janitor）

2026-11-13 立项。三款新游戏之一（另两款：最后一块饼干、弹簧快递），各自在单独对话里开发。内容量最大，建议排最后。

## 定位
- 类型：走位经营（类似 Monkey Mart 的操作方式：摇杆走路，走到工位自动干活），单人
- 首投平台：Poki 或 CrazyGames 都可以（这类游戏单次时长长，广告收入高）
- 一句话：勇者刚闯完地牢，你是后勤：拖地、重置陷阱、补宝箱、修门，下一波勇者马上就到。

## 核心玩法
- 每波勇者经过后地牢变乱：史莱姆污渍、触发过的陷阱、空宝箱、破门
- 走到对应位置自动清理 / 重置 / 补货，赚金币
- 金币用来雇哥布林员工（自动干活）、买更好的工具、扩建新房间
- 勇者满意度决定收入；地牢没收拾好，勇者会投诉或者直接通关溜走
- 和坑勇者同一个世界观，可以联动（勇者造型、陷阱种类）

## 画风
- 低多边形玩具风加火把暖光，Three.js
- 用史莱姆 / 彩色污渍代替血迹（PEGI-12）
- 要有"成品感"：统一配色、柔和阴影、干活时有清楚的进度反馈和金币飞入动画

## 可复用
- 坑勇者：陷阱种类、勇者类型、世界观
- 劫匪大乱斗 / 怪物糖果夜：Three.js 斜俯视镜头、手机摇杆
- 捏捏叠叠乐：签到、每日任务、存档

## 平台硬性要求
- 打开即玩，第一分钟引导要一步一步带
- 广告只在自然停顿（扩建完成、新一天开始）；激励广告用于加速 / 双倍收入
- 手机和电脑都能玩；存档用平台 SDK（CG Data 模块 / 本地存储）
- 11 种语言（en fr it de es tr zh ja ko pt ru）

## 工作流规则（用户规定）
- 在 GitHub 建测试仓库，公共测试链接用 GitHub Pages
- 提交表单不选任何 AI 相关选项

## 原“待新对话决定”——已于 2026-11-13 定下
- 房间和员工数值曲线：8 个房间（120 起，约 ×2.3–2.6），3 种哥布林各 3 个，工具 3 样各 5 级，单一金币，约 45 分钟开满
- Boss / 特殊事件：都做——每第 3 天勇者王；第 2 天起每天一个随机事件（史莱姆爆发、巡查员、小偷、旅行团）
- 离线收益：做，需至少 1 个哥布林，25% 效率，最多 2 小时，可看广告翻倍
- 详细数字和开发进度见 `claude/地牢保洁公司-开发交接.md`
