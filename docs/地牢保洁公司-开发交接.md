## v0.2 改了什么（用户反馈 v0.1：“玩不懂，也不好玩”）
看 v0.1 截图发现：干活和赚钱隔太远（收拾完要等 30 秒一波，勇者在别处走过）、金袋堆在旁边另一个屋子、大段时间没事干、角色太小。v0.2 核心循环改成 Monkey Mart 式：
- **勇者一个接一个来**（约每 3–8 秒一个，同时最多 2+房间数个），在每个陷阱 / 宝箱前**停下来用**。
- 没准备好就**站着等**：头顶大气泡显示要什么（🔧 陷阱 / 💰 宝箱），外圈耐心条（绿→黄→红，15 秒）。等不到就生气（😡 太慢了）跳过，少给钱、口碑掉。
- 你修好，勇者马上用，**金币掉在站点旁边成一堆**，走过去自动捡（飞进左上角）。
- 勇者走路偶尔留史莱姆，别的勇者踩到会**滑倒**（耐心 -2、满意度降）；拖掉给 1 金币。
- 取消了“天/波”和门；顶部改成“下一个房间：X ● 已有/价格”进度条。插屏广告放在扩建完成后。勇者王每 25 个勇者来一次（5 倍钱）。事件（小偷、巡查员等）暂时去掉。
- 房间缩小（10×9），镜头拉近，金袋堆、工具台、雇佣格子都在入口大厅里。没有储藏室了。
- 价格：宝箱库 60 → 陷阱走廊 220 → 史莱姆洞 650 → 骷髅墓穴 1700 → 熔岩桥 4500 → 冰晶厅 12000 → 龙穴 30000；收费倍率 1.75^房间号。机器人：第 2 间 <1 分钟，第 3 间约 4 分钟，8 间约 45 分钟。
- 引导：一个骑士直接走到坏陷阱前等 → 重置 → 捡钱 → 他去空宝箱前等 → 拿金袋 → 补宝箱 → 开始连续来人、出现扩建格子 → 够钱指扩建 → 指雇清洁哥布林 → 指工具台。引导期间勇者耐心不减。

## 性能（重要）
- 用户电脑是 Intel UHD 集显，claude.ai 预览页里 v0.1/v0.2 只有约 1.5 帧/秒，截图也经常超时。这很可能也是“不好玩”的原因之一。
- v0.2 加了自动降画质：q2（DPR≤1.5、2 盏火把点光源、阴影 1024）→ q1（无点光源、DPR 1.25）→ q0（无阴影、DPR 1）；每 2 秒测帧率，<40 就降一级并记在 localStorage dj_q。左下角测试版显示帧率（SHOWFPS）。
- JS 本身每帧只有 1–4ms，瓶颈在 GPU 填充。
- 还没确认在用户电脑上降级后能到多少帧——最好在 GitHub Pages 直接打开测（不在 iframe 里）。
